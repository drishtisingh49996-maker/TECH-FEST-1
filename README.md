# CYBORG // HUMAN × MACHINE INTELLIGENCE
### Techfest IIT Bombay Campus Ambassador Task — Cyborg-Themed Landing Page Development

A production-quality, futuristic cybernetic landing page built for the **Techfest IIT Bombay Campus Ambassador Program**. 

The design combines an **Apple-level product presentation** with a **futuristic AI laboratory HUD**, reflecting the core theme:
> **"HUMAN INTELLIGENCE + MACHINE INTELLIGENCE"**

---

## ⚡ Live Features

1. **Floating Glassmorphic HUD Navbar**
   - Active section tracking with smooth scroll (`#system`, `#interface`, `#capabilities`, `#protocol`)
   - Real-time animated `[ ONLINE ● ]` status indicator
   - Mobile-responsive navigation drawer with futuristic telemetry
   - Quick "SUBMIT" action button linking directly to the task modal

2. **Hero Section & Cybernetic Core Visualization**
   - Pure CSS/SVG/Canvas animated AI core / cybernetic brain (no stock photos)
   - Dynamic orbital rings, counter-rotating telemetry arcs, and synaptic nodes
   - Subtle mouse parallax response for HUD elements and particle layers
   - Live system status panel with real-time fluctuating metrics (Neural Core %, Sync %, Core Temp)

3. **System Intro — "The Cybernetic Shift"**
   - 3 interactive futuristic cards:
     - `01 // HUMAN INPUT` (Cognitive Intent)
     - `02 // MACHINE INTELLIGENCE` (Synthetic Reasoning)
     - `03 // COLLECTIVE OUTPUT` (Hybrid Synchrony)
   - Card lift, border animations, and cyber grid reveal on hover

4. **System Capabilities Bento Grid**
   - 5 bespoke modular capability cards with custom animated micro-visuals:
     - **AI Interaction**: Real-time animated audio/frequency spectrum waveform
     - **Neural Processing**: Multi-node synaptic matrix with pulsing tensor units
     - **Cyber Security**: Concentric rotating shield scanner with post-quantum telemetry
     - **Robotics**: 6-DOF kinetic manipulator vector simulation
     - **Human Augmentation**: Bio-digital energy pulse synchronization
   - Corner brackets, 1px cyber borders, and technical metadata

5. **Interactive Neural Network // LIVE**
   - 36-node live Canvas simulation with dynamic physics and data packet propagation
   - Cursor attractor dynamics: nodes react to pointer proximity, brightening synaptic links
   - Side HUD showing node count, active links, signal integrity, and throughput

6. **Animated System Stats**
   - Viewport-triggered counters powered by Framer Motion:
     - `99.7%` System Sync
     - `42` Active Nodes
     - `04ms` Signal Latency
     - `∞` Possibilities

7. **The Protocol — Interactive Vertical Timeline**
   - 5 sequential lifecycle phases: `01 CONNECT` → `02 ANALYZE` → `03 ADAPT` → `04 CREATE` → `05 EVOLVE`
   - Scroll-driven progress line glowing with cyber gradients

8. **Submission Modal (Techfest CA Task Reference)**
   - High-fidelity modal inspired by the Techfest CA portal
   - `50 TOKENS` reward badge with animated icon
   - GitHub Repository URL & Google Drive Demo URL inputs
   - Real-time client-side URL validation with animated error states
   - Multi-stage submission sequence:
     `INITIALIZING...` → `SYNCING...` → `VERIFYING...` → `MISSION COMPLETE ✓`
   - Persistent caching in `localStorage`

9. **Cyber Microinteractions & Accessibility**
   - Custom glowing desktop cursor with hover expansion
   - Built-in Web Audio API synthesizer for futuristic click feedback (toggleable)
   - Full keyboard accessibility and `prefers-reduced-motion` compliance
   - 100% responsive across mobile (360px+), tablet, laptop, and 4K desktop

## 🚀 Getting Started

### 1. Clone & Install
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```
Open `http://localhost:5173` in your browser.

### 3. Build for Production
```bash
npm run build
```
